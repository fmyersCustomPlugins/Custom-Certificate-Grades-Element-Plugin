# READ ME FIRST - Quarterly Totals Certificate Element

## What this is

A Moodle certificate element that automatically lists every course a
student is enrolled in, with their Quarter 1-4 and Final grades, as one
report-card-style table on a certificate.

## Where to get the file

The zip file to install is:

**`customcertelement_quarterlytotals.zip`**

This should be located in the same folder/download location as this
README. If you don't see it there, ask whoever shared this README where
it's stored.

## How to install it

1. Log in to Moodle as a site administrator.
2. Go to **Site administration > Plugins > Install plugins**.
3. Upload `customcertelement_quarterlytotals.zip` using the uploader on
   that page.
4. Moodle will detect it automatically as a certificate element plugin.
   Follow the on-screen steps to confirm and complete the install.

## After installing

1. Go to **Site administration > Plugins > Activity modules >
   Certificate** (or search "quarterlytotals" in the admin settings
   search box) to set text/background/border colours if you want
   something other than the defaults.
2. Open a certificate template's editor.
3. Choose **Quarterly totals** from the "Add element" dropdown.
4. Position it on the certificate. That's it - it automatically fills in
   with whichever courses each student is enrolled in when certificates
   are issued.
